# 週替わり練習メニュー

走り方教室の練習メニュー表をもとに、**毎週のテーマと練習メニューを自動で選んで表示する**スマホ向けWebページです。

知人の指導者から「紙の表から毎週メニューを選ぶのが大変」と相談を受け、要件を聞き取りながら作りました。

## できること

- 毎週（練習日は火曜）のテーマとメニューを自動で選ぶ
- 1か月分の練習をまとめて表示し、前後の月に移動できる
- 開いた日の月から表示し、今週の練習を強調する
- 同じ週なら、誰がどの端末で開いても同じメニューが出る（サーバー不要）

## 選び方のルール

| 項目 | 選ぶ数 | ルール |
|---|---|---|
| テーマ | 1 | 4テーマからランダム。前の週と同じテーマは続けない |
| 筋トレ | 1カテゴリ×3種目 | 全テーマ共通の候補から。前の週と同じカテゴリは避ける |
| アクティビティ | 2 | テーマの候補から。足りなければ他のテーマから補う |
| メイン活動 | ドリル4＋ドリル以外1 | ドリルはテーマから（足りなければ他テーマから補う）、ドリル以外は他テーマから1つ |
| 〆 | 1 | 2種類から |

種目もできるだけ前の週と違うものを選びます。他のテーマから補った種目には「補充」と表示します。

## 仕組み

- HTML / CSS / JavaScript の1ファイル。ビルドやサーバーは不要
- 起点の週からの週番号を乱数のシードにして（mulberry32）、前の週の結果を見ながら1週ずつ順に生成する。そのため、ランダムでも全員に同じ結果が出て、「前の週と被らない」条件も守れる
- 週の表記は練習日（火曜）基準。「11月第1週」は、その月の1回目の火曜を指す

## 使い方

`index.html` をブラウザで開くだけです。GitHub Pages で公開すればスマホから見られます。

メニューを変えるときは、`index.html` 内の `THEMES`（テーマごとのアクティビティ・ドリル・ドリル以外）、`STRENGTH`（筋トレ）、`FINISH`（〆）を編集します。

## 開発の分担

- 要件の聞き取り、仕様の判断（選び方のルール、表示の仕方）：自分
- 実装：生成AI（Claude）を活用
- 利用者の要望を受けて改善：週表示 → 4週一覧 → 月ごとの表示・火曜基準へ変更
